# genpark-agent-b2b-contract-negotiation-copilot-skill

Autonomous B2B contract negotiation copilot analyzing counterparty concession velocity, contractual leverage, and generating strategic counter-offers.

## Architecture
- **Input**: Pricing quotes, proposed discount thresholds, and commitment periods.
- **Engine**: Margin boundary validation and give-get term generator.
- **Output**: Counter-offer recommendations and executive negotiation playbook.
